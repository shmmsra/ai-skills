# vocal-ai

Generate speech (WAV) from text via the local, offline `vocalai` CLI — for demo-recording narration, voiceovers, or any text-to-speech need. Includes a setup/update flow for fetching the `vocalai` binary and its ONNX models.

**Source**: https://github.com/shmmsra/ai-skills
**Skill path**: `skills/vocal-ai/`
**Version**: see `VERSION` file in this directory

This file is installed alongside the skill. To update to a newer version, re-run the installer with `--update` (shell) or `-Update` (PowerShell), or check the source repo for the latest release.
